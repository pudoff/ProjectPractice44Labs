## Повторение

Из корня проекта с Python 3.12 и зависимостями общего backend/CV:

```powershell
python -X utf8 docs/reviews/2026-11-11-ocr-fixes/run_validation.py unit --out .local-backups/ocr-check-new/unit
python -X utf8 docs/reviews/2026-11-11-ocr-fixes/run_validation.py cv --out .local-backups/ocr-check-new/cv
```

Каталоги результата должны быть новыми. Скрипт использует временный SQLite и файловое хранилище, не обращается к рабочей БД. Он явно убирает `TEST_DATABASE_URL` из окружения дочернего процесса проверки. Для CV требуются подготовленные локальные файлы `models/` и проверяемый `models/manifest.local.json`; загрузка весов из сети в этом запуске не используется. Подготовка конфигурации CV не загружает и не запускает PaddleOCR.

Использованный интерпретатор: `.local-backups/fix-20261031/venv/Scripts/python.exe`. Финальный общий прогон выполнен этим скриптом. CV выполнен эквивалентным вызовом `configure_local_models()` и `pytest.main(['-q', 'mlcv/tests', ...])` с локальными моделями, временным хранилищем и отключённым запуском Paddle. Общий CI содержит отдельные контейнерные, PostgreSQL и настоящие OCR-проверки; они здесь не подменяются модульными тестами.

## Проверяемые сценарии

Новые регрессии находятся в:

- [тексты, сбои, масштабы и связи](../../../mlocr/tests/test_review_fixes.py);
- [честность оценщиков и сохранение входов](../../../mlocr/tests/test_evaluation_integrity.py);
- [опоры, точность, DXF и передача ошибок backend](../../../backend/tests/test_ocr_review_fixes.py).

Проверки дополняют прежние положительные сценарии. Исправлены две старые проверки: свободная точка внутри отрезка заменена ожидаемой ссылкой на него; в примере неоднозначности обе пары выносных линий теперь действительно доходят до детали.

Числа из исторических QA-таблиц и отчётов не пересчитывались и не считаются независимой оценкой текущего OCR. Для оценки по DXF `score_on_references.py` использует сравнительную форму `canon`: декодирует управляющие символы и нормализует пробелы, регистр и похожие буквы алфавитов. Его CER относится к этой сравнительной форме; QA-оценщик считает ошибки по размеченным строкам после правил без такого свёртывания алфавитов. Методики и знаменатели нельзя смешивать.

## Ограничения

Не выполнены новый прогон PaddleOCR по реальным листам, независимая ручная разметка, PostgreSQL/контейнеры и CAD GUI. Docker проверен обычным и разрешённым запуском: локальный Docker Engine недоступен. Наличие нативной сущности DIMENSION и её пересчёт по DrawingGraph не доказывают ассоциативность внутри CAD.
