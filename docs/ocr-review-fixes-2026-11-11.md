Основание — ревью коммита `6f5263315ccecf92693938f78994a874d98584e6`. Для интеграции взят `main` версии `730be13686bfb4486f60809214b9a2ed43af343d`. ## Разрешение конфликтов с main

В `dimension_geometry.py` объединены новый поиск фактической размерной линии и проверки неоднозначности из `main`. Сохранены проверки основания на контуре и угловой точки, перенос замечаний и первоначального OCR-чтения из адаптера `main`.

Объединение похожих гипотез больше не скрывает разные измеряемые объекты: совпасть должны опоры и объекты детали. Стрелка около одного варианта не отменяет второй допустимый вариант на другой детали. Это проверяется отдельным отрицательным примером.

Неиспользуемая ветка подтверждения без размерной линии удалена. Если размерная линия не обнаружена или опора на кривой пока не поддерживается, сохраняются исходный текст и замечание. Это сознательное ограничение MVP; размеры не подтверждаются по одному совпадению числа и расстояния.

## Дополнение контракта опорных точек

Формат DrawingGraph остаётся **0.2**. Добавлен необязательный параметр ссылки:

```json
{
  "object_id": "part-edge",
  "anchor": "segment",
  "parameter": 0.25
}
```

Это точка на четверти отрезка от начала к концу: `start + parameter × (end − start)`. Параметр обязателен для `segment`, ограничен диапазоном 0…1 и запрещён для других типов опор. Прежние ссылки `start`, `end`, `mid` работают как раньше. Положение пересчитывается backend перед повторным экспортом.

Такое описание сохраняет относительную точку на отрезке. Оно не является решателем геометрических ограничений или автоматическим поиском нового пересечения после произвольного редактирования. Ассоциативность внутри CAD проверяется отдельно.
