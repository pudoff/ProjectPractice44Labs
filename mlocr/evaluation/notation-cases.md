# Обозначения и исправления OCR

Обновлено после интеграции 01.11.2026. `raw_text` хранит первоначальное чтение; исправленный текст и правило записываются отдельно. Таблица описывает обработку строк, не гарантирует точность распознавания изображения.

| Исходное чтение | Результат | Ограничение |
|---|---|---|
| `Сm3`, `деmаль` | `Ст3`, `деталь` | Замена только внутри слова с кириллицей |
| `10m`, `item`, `M12`, `медь` | Без замены | Латиница, резьба и кириллическая м сохраняются |
| `8omb.` | `8отв.` | Отдельное правило полного сокращения после числа |
| `Ø20`, `⌀20`, `∅20`, `φ20`, `Ф20`, `O/20` | `Ø20`, тип diameter, 20 | Только позиция знака перед числом |
| `O20`, `020` | Знак Ø не добавляется по строке | Без изображения буква/ноль неоднозначны |
| `32`, если перед цифрами виден перечёркнутый круг | `Ø32` | Нужны признаки изображения; needs_review и diameter_recovered |
| `8отв.4`, если перед 4 виден такой знак | `8отв.Ø4` | То же правило по изображению; отверстий 8 |
| `46` | Линейный кандидат, 46 | Связь с геометрией проверяется отдельно |
| `R2` | Радиус, 2 | Автоматический радиальный DIMENSION пока не поддержан |
| `46±0,1` | Номинал 46, допуск 0,1 | Номинал не подменяет измерение геометрии |
| `M12×1,5`, `M56x2-7H` | Резьба и её параметры | Не обычный линейный размер |
| `1:5` | Масштаб 0,2 | Только положительные конечные числа |
| `R0`, `Ø-2`, `1:0`, `46±-0.1`, `10 20` | Недопустимое значение/замечание | Не принимаем нулевой радиус, отрицательный диаметр, деление на ноль и склеенные числа |
| `Ø2O±O,l` | unknown | Нет общей подмены O/l числами 0/1 |

Реальный OCR на фрагментах бобышки, втулки и крышки: [метрики и первоначальные чтения](../../docs/reviews/2026-11-01-ocr-fixes/ocr-crops/metrics.json). Разметка подготовлена при исправлении; независимая приёмка CAD/QA ещё нужна.
