# Примеры разбора инженерных обозначений

Таблица проверяет семантический разбор, а не качество распознавания OCR. В `raw_text` всегда сохраняется исходное чтение. Автоматические исправления OCR не выполняются.

| Исходная строка | Ожидаемый результат парсера | Текущий результат парсера | Примечание |
|---|---|---|---|
| `46` | линейный размер, номинал 46 | `linear`, 46 | Кандидат линейного размера; смысл подтверждается только с учётом контекста |
| `Ø20` | диаметр, номинал 20 | `diameter`, 20 | Специальный знак диаметра |
| `⌀20` | диаметр, номинал 20 | `diameter`, 20 | Специальный знак диаметра |
| `∅14` | неоднозначный кандидат диаметра, номинал 14 | `diameter_candidate`, 14 | Пример из текстового слоя PDF; символ не заменяется на `⌀` |
| `φ72` | неоднозначный кандидат диаметра, номинал 72 | `diameter_candidate`, 72 | Так OCR прочитал знак на примере гайки |
| `Ф14` | неоднозначный кандидат диаметра, номинал 14 | `diameter_candidate`, 14 | Похожая кириллическая буква сохраняется как есть |
| `R2` | радиус, номинал 2 | `radius`, 2 | Обозначение радиуса |
| `46±0,1` | линейный размер с допуском: номинал 46, допуск 0,1 | `linear_tolerance`, 46, 0,1 | Десятичная запятая разбирается численно; исходная строка сохранена |
| `M12×1,5` | резьба: номинал 12, шаг 1,5 | `thread`, 12, 1,5 | Не классифицируется как обычный линейный размер |
| `M56x2-7H` | резьба: номинал 56, шаг 2, класс 7H | `thread`, 56, 2, 7H | Латинский `x` распознаётся как разделитель шага |
| `1:5` | масштаб: числитель 1, знаменатель 5 | `scale`, 1, 5 | Не классифицируется как длина |
| `Ø2O±O,l` | неподдерживаемое обозначение | `unknown`; исходная строка сохранена | Нет автозамены `O` на `0` или `l` на `1` |

Парсер интерпретирует только поддерживаемую форму строки. Он не доказывает, что символ имеет нужное значение на конкретном чертеже или что надпись относится к конкретному элементу геометрии.
