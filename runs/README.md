# Прогоны на конкретных листах

Каждая папка — один лист (или серия) со своим отчётом. Устройство папки прогона:

| путь | что |
|---|---|
| `REPORT.md` | отчёт: что сделано, метрики, расхождения, как открыть в CAD — **начинать с него** |
| `out/` | итоговые файлы (DXF, DWG), замороженные копии для сравнения, результаты проверки в LibreCAD и ODA |
| `compare/` | сравнения с эталоном (`report.md`, `overlay.png`) и проверка наложением на исходный PNG |
| `work/` | измерения и вспомогательные скрипты, которыми строился результат |

| прогон | лист | итог |
|---|---|---|
| [`klapan_png2dxf/`](klapan_png2dxf/REPORT.md) | `клапан.png` — «Клапан предохранительный», А3, 1:1 | вариант A (`out/klapan_variant_A.dxf`, рекомендуемый) и вариант B (`out/klapan_variant_B.dxf`) |

Код в `klapan_png2dxf/pipeline_b/` — прототип автоматического конвейера; его перенос в пакет сервиса описан в
[`docs/architecture/ARCHITECTURE.md`](../docs/architecture/ARCHITECTURE.md). В конвейер уже внесены исправления,
найденные ревью, поэтому его текущий результат отличается от замороженного `out/klapan_variant_B.dxf`
(см. [`docs/architecture/experiments/RESULTS.md`](../docs/architecture/experiments/RESULTS.md)).
