# Вариант B — автоматический конвейер PNG/скан → DXF (ЕСКД)

Проект: совместная работа с 44labs (оцифровка архивных чертежей).

```bash
.venv/Scripts/python runs/klapan_png2dxf/pipeline_b/pipeline.py INPUT.png OUT.dxf [--sheet A3] [--report report.json]
```
Без ручного ввода геометрии: всё, что знает конвейер о листе, извлекается из растра.

| этап | модуль | что делает |
|---|---|---|
| загрузка | `raster.py` | Otsu, оценка перекоса по длинным линиям (Hough) и выравнивание, калибровка px↔мм по линии обреза листа |
| OCR | `ocr.py` | RapidOCR (ONNX, PP-OCRv6 det + PP-OCRv5 **eslav** rec: кириллица+латиница+цифры), 2 прохода (0° и 90°), слияние; формат листа из «Формат А3» |
| символы | `symbols.py` | стрелки (морф. открытие + PCA, остриё — до пересечения с выносной), зачернённые треугольники баз, точки |
| векторизация | `vectorize.py` | скелет → цепочки → отрезки/дуги (рекурсивное деление, допуск 0,08 мм) |
| чистка | `postproc.py` | слияние коллинеарных, привязка углов к 15°, штриховые/осевые цепочки (с проверкой «разрыв пустой») |
| штриховка | `hatch.py` | семейства параллельных равноотстоящих отрезков → HATCH ANSI31 (шаг и фаза измерены), контур — заливкой по контурным линиям |
| размеры | `dims.py` | пары соосных встречных стрелок → DIMENSION; выносные; текст = ближайшая OCR-строка, совпадающая по значению с измерением (или масштаб вида 2/2,5/4/5/10 → DIMLFAC); ⌀ по симметрии относительно оси; R — стрелка на дуге + надпись «R…» (с целевым дозапуском OCR); угловые; выноски (LEADER) |
| подгонка | `pipeline.py:snap_to_dims` | МНК-сдвиг кластеров координат x/y, чтобы геометрия точно удовлетворяла распознанным размерам |
| штамп | `pipeline.py:title_fields` | поля ГОСТ 2.104 ф.1 → TEXT + пользовательские свойства DXF (`$CUSTOMPROPERTY`) для поиска в архиве |
| запись | `eskd_dxf.new_drawing` | AC1021, UTF-8, мм, слои MAIN/THIN/AXIS/DIMS/TEXT, настоящие DIMENSION |

Время на листе А3 600 dpi (9925×7017), CPU (ноутбук, без GPU): ≈ 13,5 с
(загрузка 3,0; OCR 3,5; символы 0,2; векторизация 3,4; штриховка 0,3; размеры 1,4; чистка 1,4; запись 0,1).
Зависимости: numpy, scipy, opencv-python-headless, scikit-image, ezdxf 1.4.5, rapidocr 3.10 + onnxruntime (веса моделей
скачиваются в пакет rapidocr при первом запуске; для офлайн-поставки — положить их в образ).

Известные ограничения: шрифт текста в DXF — isocpeur (не совпадает с исходным), ⌀ восстанавливается по симметрии/OCR,
надписи, не прочитанные OCR, остаются векторными штрихами; штриховка находится не во всех областях; классы MAIN/THIN
при одинаковой толщине штрихов решаются эвристикой.
